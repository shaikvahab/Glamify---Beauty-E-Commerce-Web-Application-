Glamify - Beauty E-Commerce App 💄✨
Glamify is a sleek and modern beauty e-commerce platform offering a delightful shopping experience for skin, hair, and body care products. Built with a robust tech stack, it provides a feature-rich and user-friendly interface with responsive design and smooth navigation.

🛠️ Tech Stack
Frontend
React: Component-based architecture for building dynamic and interactive UI.
React Router: Seamless navigation between pages with a single-page application (SPA) approach.
Tailwind CSS: Utility-first CSS framework for responsive and visually appealing designs.
Development Tools
Vite: Fast build tool and development server for React projects.
npm: Dependency management and script execution.
Icons and Animations
React Icons: Beautiful icons for enhancing UI elements.
CSS Transitions: Smooth hover effects and animations for interactive components.
🌟 Features
Product Listings: Explore a range of skin, hair, and body care products.
Search Functionality: Find products quickly with an intuitive search bar.
Category-Based Shopping: Browse and shop by categories using dropdowns and detailed product pages.
Cart Management: Add items to the cart, adjust quantities, and proceed to checkout.
Order Confirmation: Animated confirmation on successful purchases.
Ask Expert: Submit queries or browse FAQs for beauty tips and product recommendations.
About Us: Discover the mission and story behind Glamify.
🖌️ Tools Used
Code Editor: Visual Studio Code
Version Control: Git & GitHub for collaboration and code management.
Design Tool: Tailwind CSS for consistent styling.
Assets: React Icons for branding and icons
